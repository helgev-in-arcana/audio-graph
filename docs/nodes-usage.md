# Nodes

`AudioGraph.vst3` や `AudioGraph.clap` 1つにインストゥルメント、エフェクト両方入っています。

AddNodeもしくは空白を右クリックでノードを配置します。

Plugin foldersでプラグインのスキャンディレクトリを登録します。

設定はユーザーごとの領域（Windows は `%LOCALAPPDATA%\AudioGraph\config.json`、
macOS は `~/Library/Application Support/AudioGraph/`、
Linux は `$XDG_CONFIG_HOME/audio-graph/`）に保存され、同じマシンの全インスタンスで共有されます。

ノード操作はBlenderのノードを参考にしています。

上部の2つの設定はパッチごとに保存されます。

- Parameter resolution — パラメーターの値を何サンプルごとに計算し、サブプラグインへ送るか。
  1 / 4 / 16 / 32 / 64 / 128 から選び、既定は 32（48kHz で約0.67ms）。
  小さいほど滑らかですが、動いている値はその間隔ごとに1イベントになります。
  オーディオの処理単位（Sub-block）とは独立しています。
- Sub-block — オーディオのフィードバックループを含むパッチが一度に処理するサンプル数で、
  オーディオ遅延の最短時間でもあります。16 / 32 / 64 / 128、既定は 32。
  小さいほどループ内のプラグインが頻繁に呼ばれます。

拍の長さ（LFO の rate の beats、MIDI Delay の sync 時の time）は DAW と同じく分数で指定します。
`[分子] / [分母▾] [3]` の形で、分子は 1〜64 の整数、分母は 1 / 2 / 4 / … / 64 から選び、
[3] で3連符（長さが 2/3）になります。単位は拍なので、4分の4拍子で 1/4 は16分音符です。

## Audio

ソケットは青、サイドチェインが紫

色分けしていますが交互に繋げることができます

- Audio I/O
- Mix
  - 各入力のゲイン（dB）はソケットで駆動できます。駆動したゲインは、パラメーター精度の点と点のあいだを
    直線でつないでサンプルごとに動くので、精度が粗くても段差になりません（ブロックの境目も同じです）。
- Audio Gate
  - control が閾値以上でゲートが開きます（[invert] で下側が開く側になります）。
  - [fade in] / [fade out] はゲインが閉から開まで渡りきる時間をミリ秒で指定します。
    0 は瞬時に切り替わり、大きい音を切ればクリックが出ます。既定の 5ms は
    クリックを消しつつリズムに使っても遅れて聞こえない値です。
  - 開閉のタイミング自体はパラメーター精度の単位（既定の 32・48kHz で約0.67ms）で、
    フェードはその境目の「形」を変えるものです。傾きが一定なので、30%まで開いた
    ところで閉じれば fade out 時間の30%で閉じきります。
- Audio Math
  - サンプルごとの演算を [op] で選びます。
    - Remove DC: 直流成分（一定のオフセット）を取り除きます。5Hz の1次ハイパスで、
      ピアノの最低音（27.5Hz）には触れず、オフセットは0.1秒ほどで消えます。
      整流や波形整形のあとに残るオフセットの掃除に。
    - Invert: 極性を反転します。
    - Rectify: 絶対値（全波整流）にします。
    - Multiply: 2つ目の入力 [by] との積（リングモジュレーション）。[by] が未接続なら
      入力をそのまま通します。
  - [by] は Multiply 以外では使われません（行に unused と出ます）。
  - Remove DC の内部状態は、他のノードを編集して再コンパイルしても引き継がれます。
- Audio Tremolo
  - キースイッチを押している間（または押してから止めるまで）、音声を指定した音価で刻みます。
    リリースカット系の表現を、録音を手で切り貼りせずに作るためのノードです。
  - [keys] に MIDI を繋ぎます。キーの設定は MIDI Tremolo と同じで、同じ設定・同じ MIDI を
    繋いだ MIDI Tremolo とはサンプル単位で同じ位置で刻みます。
  - [fade in] / [fade out] は Audio Gate と同じく、鳴っている側と切れている側を渡りきる時間（ミリ秒）です。
    0 は瞬時に切り替わり、大きい音を切ればクリックが出ます。刻みがフェードより短いと端まで届きません。
  - キースイッチが動いていないときは素通しです。

## Granular

Audio のメニューにあります。`Audio In` に音声、`Keys` に MIDI、`Audio Out` に出力先をつなぎます。
順方向・等速・固定 Hann 窓の粒を、ライブ録音した履歴から重ねて再生します。

### 配置と履歴

ノード表面には Audio Out / Audio In / Keys、Keys直下に **Dry / Wet**、
録音状況と **Input control** / **Output control** のキー表が並びます。
タイトルの **⚙** で全設定の浮動画面を開きます。画面外のクリックまたはEscapeで閉じます。
設定は編集時に反映されます。History / Block sizeなどは `1/4` のような分数入力とプリセットも使えます。

- **capacity (s)** — 確保する最大時間。既定4秒、最大10秒。編集すると素材を消します。
- **History (beats)** — 一回の録音で使う履歴長。既定2拍。
  **Recordを押した時点のテンポでサンプル数へ変換し、その録音中・録音停止後は固定**します。
  例えば4拍・120 BPMなら2秒。その後60 BPMになっても2秒のままで、次のRecordから4秒を要求します。
  capacityを超える分は容量までに制限します。録音素材をテンポに合わせてストレッチする機能はありません。
- **Recorded A / B s** — 実際に録音済みの長さと、その録音で確定した履歴長。
  未録音部分は読みません。Record / Play の状態も表示します。
- **Block size (beats)** — 入出力共通の音楽的な区間長。既定1/4拍（16分音符）。
  録音側はRecord、再生側はPlayを起点に区切ります。テンポ・Block設定の変更はそれぞれの次の区間から反映し、
  録音済みの区間の位置と長さは変更しません。DAWの小節頭へ同期する機能ではありません。
  区間の下限は1 ms（少なくとも4サンプル）です。
- **loop recording** — 満杯で最古から循環更新するか、最初の履歴長分を保持して追加入力を捨てるか。
  循環方式は録音中も反映します。満杯で停止中でも、Recordを保持したまま循環を有効にすると書き込みを再開します。
- **update on wrap** — 二周目以降の更新比率。1は置換、0.5は旧音と入力を半分ずつ、0は旧音を保持。
  最初の一周は入力をそのまま記録します。DAWの処理ブロック長には依存しません。

### キーに操作を割り当てる

Input / Outputの各領域にある `+ key` でキーの行を追加し、操作ボタンから割り当てを選びます。
Input側では録音・履歴の操作、Output側では粒再生の操作だけを選べます。
一つのキーはノード内に一行だけ置けます。同じ操作を複数のキーへ割り当てることはできます。

| 初期キー | 操作 | 動作 |
| --- | --- | --- |
| 24 | Record | 押すたびに履歴を消して新規録音。押下中は書き込み、離すと保持 |
| 25 | Reset | 録音・発音・履歴を初期化。ノブ値と割り当て設定は維持 |
| 26 | Play | 粒の生成。再打鍵で再生時計を始め直し、既存粒は完走 |
| 27 | Stop | 新粒生成を止め、既存粒は完走。録音は止めない |
| 28 | Size 1/2 | 粒長をブロックの1/2へ |
| 29 | Interval 1/4 | 発音間隔をブロックの1/4へ |
| 30 | Position 0 | 最古側の録音区間を選択 |

InputメニューはRecord / Reset / History / Block / Invert loop recording / 更新比率。
OutputメニューはPlay / Stop / Size / Interval / Position / Wetです。
数値操作は値を設定でき、分数のプリセットボタンもあります。

Playと数値・フラグ操作は、キーごとに **Hold / Select** を選びます。
Holdは押下中、Selectは離鍵後も保持します。このモードは同じキーの全ベロシティ帯に共通です。
Recordは常にHold、Reset / Stopは常にNote On時の単発操作です。

### 基準値とMIDI

- **数値**：設定画面とMIDI Selectは同じ基準値を更新します。後から編集した値が基準値になります。
  Hold中は対象ごとの後押し優先で一時上書きし、全て離すと最新の基準値に戻ります。
  Hold中にもUIやSelectで基準値を変更できます。数値のSelect結果は画面にも反映され、プロジェクトに保存されます。
- **フラグ**：Loop recordingの基準値に対して、キー有効時はOn / Offを反転します。
  Holdは押下中だけ反転し、複数キーはORです。二つ押しても元には戻りません。
  Selectは反転を有効にして離鍵後も保持します。押し直しても解除しません。
  Resetで反転を解除します。反転の保持状態は保存せず、Loopの基準値を保存します。
- **適用時期**：Historyの基準値が変わっても、現在の録音済み長さ・履歴長は変えず、次のRecordから適用します。
  Block sizeは入出力それぞれの次の区間、Size / Interval / Positionは次の粒生成に反映します。

### ベロシティ分割

行の **vel** ボタンを有効にすると、そのキーの下にベロシティ帯と操作が並びます。
初期分割は1〜63 / 64〜127。境界を編集し、`+ band` で帯を増やせます。
帯は1〜127を隙間・重複なく覆います。velを無効にすると先頭の操作を強さに関係なく使い、
他の帯の設定は保持します。一ノードの有効な割り当ては最大64帯です。

例えば同じキーの弱い帯に Interval 1/2、強い帯に Interval 1/4 を設定できます。
Blockが1拍なら、それぞれ8分音符・16分音符の間隔です。値はブロックに対する比率です。

### 同時押し・復帰・再押下

- **対象ごとの後押し優先**：粒長や間隔など、同じ対象のHoldは最後に押したキーが有効です。
  `A-On → B-On → B-Off → A-Off` なら `A → B → A → 基準値`。
  異なる対象、例えば粒長と間隔は同時に有効になります。
- **OR**：同じRecord / Playに複数キーを割り当てた場合、どれかが押されていれば有効です。
  Recordの新しいNote Onでは録り直しますが、別のRecordキーを離しただけでは録り直しません。
- **単発操作と復帰の区別**：Holdの復帰では、Resetや時計の再始動を再実行しません。
- **同じチャンネル・同じキーの再押下**：旧押下を解除したものとして、新しいベロシティ帯へ置き換えます。
  旧帯は復帰候補に残りません。Note IDの有無に関係なく、次に届く同一キーの最初のNote Offで現在の押下を解除します。
  続くNote Offは押下がなければ何もしません。チャンネルが違えば独立した押下です。
- **Stop / Reset**：保持中のPlayも解除します。キーを押したままでも勝手に再開せず、新しいNote Onを待ちます。

### 出力のMIDI操作とDry/Wet

| パラメーター | 意味 |
| --- | --- |
| Size | 粒長の比率。0.05〜1、既定0.5 |
| Interval | ブロック内の発音間隔の比率。0.05〜1、既定0.25。各ブロック頭でも粒を生成 |
| Position | 録音区間を選択。0が最古、1が最新。途中値は区間番号へ丸める |
| Dry / Wet | 原音と粒の混合。0〜1、既定0.5 |

**Block sizeは書き込みスライスと再生側の基準区間に共通の長さ**です。
**Size / blockは、その区間に対する粒1個の長さの比率**です。
例えば120 BPM、Block sizeが1/4拍なら区間は125 ms、Size / blockが1/2なら粒長は62.5 msです。
Size / blockだけを変えても、録音の区切りや再生側の基準区間長は変わりません。

Size / Interval / PositionはOutputのキー表からMIDIで制御し、基準値は⚙画面でも変更できます。
操作ごとの値はキー行のメニューで設定します。ノード表面に個別の数値行やパラメーター入力ソケットはありません。
Dry/WetはKeys直下のパラメーター入力ソケットです。未接続時はノブで調整でき、OutputのWet操作も割り当てられます。
接続時はソケットの値がノブとMIDIのWet操作に優先します。値は0〜1に制限し、他の音声パラメーターと同様に補間します。
Granularの入力ソケットは `Audio In`、`Keys`、`Dry / Wet` の3つです。Size / Interval / Positionへの数値ソケットはありません。
Granular内部のキー操作はサンプル単位です。

粒は選んだ録音区間の先頭から読みます。完成した区間が粒より短ければ短縮し、録音途中なら必要な音を待ちます。
粒の位置・長さは生成時に確定し、既存粒へ新しい値を適用しません。
発音していない間は原音を通し、Play中の粒の隙間では設定したWetを保ちます。
停止や録り直しの切り替えは約5 msで滑らかにします。一ノード64粒、同時8ノードまでです。

### 保持と保存

無関係な編集・再コンパイルとDAWのresetでは録音素材を保持します。
DAWのresetはRecord / PlayのHoldと既存粒を終了し、SelectのPlayは時計を始め直します。
キー表を編集するとHold、Playの保持、フラグの反転を解除します。数値の基準値は維持します。
通常の数値編集では保持中のキーを失いません。Resetでも数値の基準値は維持します。
capacity / sample rateの変更、ノードReset、エディタ全Resetでは素材を消します。
**録音音声はプロジェクト保存に含まれません。**

秒指定のHistoryと操作別キー欄を持つ旧プロトタイプのGranular設定とは形式が異なります。
旧ノードのデータは未対応ノードとして保持されるため、新しいGranularを配置し直してください。
明示的なLoop / Stop at end割り当てもInvert loopへ形式が変わっています。旧割り当てを含むノードは未対応ノードとして保持されます。
分数形式のHistory / Block設定はその拍数を維持して読み込みます。

## MIDI

ソケットは黄色

MIDIはDAWと同じくフルチャンネルで扱います。ノートもコントローラーも
オーディオやパラメーターと同じ「グラフ上の線」で、どのプラグインに何が
届くかは配線が決めます。

- MIDI In
- MIDI Gate
- MIDI Merge
  - 複数のMIDIストリームを1本にまとめます。[+] で入力を増やせます（最大8）。
  - イベントは時刻順に並べ直されます。同じ時刻なら上の入力が先です。
  - MIDI Split などで分けた流れを合流させても、同じノートやコントローラーが二重には
    なりません（別の入力からすでに入った同一イベントは捨てます）。同じ鍵盤でも別の
    ノートは別物として両方通り、1本の入力の中で繰り返されたイベントはそのまま残ります。
  - 入力が1本しかつながっていなければ、その流れをそのまま出します。
- MIDI Delay
  - MIDIストリームを遅らせます。時間は秒、または [sync] で拍（ホストのテンポに追従）。
    拍は分数で指定します（下の「拍の長さ」）。秒と拍はそれぞれ保持されるので、
    [sync] を切り替えても元の値に戻れます。
    [time] はソケットで駆動できます。ソケットの値は拍数（sync 時）か秒の数値です。
  - ノートもコントローラーも同じだけ遅れるので、ペダルは押したときのノートと一緒に届きます。
  - フィードバックはありません。繰り返しは、Delay を並べて MIDI Merge でまとめて作ります。
  - 遅延中に時間を短くしても、ノートオフがノートオンを追い越すことはありません
    （後から入ったイベントは、先に入ったものより前には出ません）。
  - 遅延中のノートは他のノードを編集して再コンパイルしても失われません。
    リセットや All Notes Off では捨てられます。一度に保持できるのは256イベントまでで、
    溢れた分は失われたノートとして通知されます。
- MIDI Tremolo
  - キースイッチを押している間（または押してから止めるまで）、押さえているノートを指定した音価で
    刻み直します。リリースカット系の表現を、MIDI を手で切り貼りせずに作るためのノードです。
  - [mode]
    - Hold: キーを押している間だけ刻みます。刻み中に別の行のキーを押すとそちらに替わり、
      離すとまだ押さえているほうに戻ります。
    - Select: キーを押すと刻み始め、[stop] のキーか別の行のキーを押すまで続きます。
      同じキーをもう一度押すと、その時点から刻み直します。
  - 行ごとにキーと1歩の長さ（拍、分数）を持ちます。[+] で行を増やし、[x] で減らします（最大8）。
  - 刻みの起点はキースイッチを押した瞬間です。DAW の小節線には揃えないので、刻みの位相は
    キースイッチを置く位置で決まり、再生を止めていても動きます。
  - [sound : cut] は1歩のうち鳴らす長さと切る長さの比です。1:1 なら半分鳴らして半分切ります。
  - 刻むのは元の演奏だけです。
    - 1歩の鳴っている間に弾いたノートはすぐ鳴り、切れている間に弾いたノートは次の歩から鳴ります。
    - 元のノートを離せば、歩の途中でもそこで終わります。
    - キースイッチを離す（止める）と刻みをやめます。そのとき鳴っていたノートは元の note-off まで伸び、
      切れていたノートは鳴り直しません。
    - 打ち直しのノートは元のノートと同じベロシティ・同じノートとして送られます。
  - スイッチに使ったキーは既定で取り除かれます（[mute switching keys]）。
  - 刻みの位置と切れているノートは、他のノードを編集して再コンパイルしても失われません。
    Select で選んだキーは再生位置の移動や All Notes Off でも残り（刻みはそこから始め直します）、
    エディタの Reset で解除されます。
- MIDI Key Mute
  - 指定したキーをMIDIストリームから取り除きます。[another key] でキーを追加、[−] で削除。ノートオン/オフの両方が取り除かれるので音は残りません。
- Key MIDI Route
  - 切り替えに使うキーは既定で取り除かれます（[mute switching keys]）。
- MIDI Split
  - 音域でMIDIストリームを分けます。出力1本が1つの帯で、それぞれの行に持つ数値は
    その帯の一番上のキー。一番上の出力は127から下へ、一番下の出力は0まで、
    それ以外は自分の数値から次の帯の1つ上まで。[+] で帯を増やし、[x] で減らします。
    減らしきると出力1本、鍵盤全体の素通しになります。
    帯は隙間なくも重なりもなく並ぶので、どのキーもちょうど1本の出力から出ます。
  - キーを持たないもの——CCやピッチベンド——はどの帯にも属さないので全出力に流れます。
    サステインペダルは全レイヤーに届きます。
- MIDI Filter
  - チャンネルとコントローラー番号で絞り込みます。keep は挙げたものだけを通し、drop は挙げたものだけを落とします。keep で何も挙げていなければ全部通ります。
- CC In
  - MIDIストリームからコントローラーを1本抜き出してパラメーターにします。チャンネルは指定なしで全チャンネル。値はメッセージの間も保たれるので、CCの来ないブロックで初期値に戻ることはありません。
- Param → CC
  - 逆向き。パラメーターをコントローラーとしてMIDIストリームに載せます。値が動いたときにだけ送るので、プラグインのパラメーターキューを埋めません。送る間隔はパラメーター精度ですが、16サンプル（48kHz で約0.33ms）より細かくはしません。コントローラーでノートの流れが埋まり、ノートオフが押し出されるのを防ぐためです。
- Velocity / Gate / Key Track / Held Keys
  - ストリームを追いかけてパラメーターにします。どれもモノフォニック — 和音でも1つの値です。Velocity と Key Track はノートの間も値を保ち、Gate は何か押されていれば1。
  - Held Keys は今押さえられているキーの数。チャンネルは見ないので ch1 と ch2 で同じキーを押しても1つ、離すのも1回で足ります。
    他の3つと違って 0..1 ではなく**生の数**（0, 1, 2, …）を出します。プラグインのパラメーターに繋ぐなら Param Map を挟んでください（パラメーターのレーンは 0..1 にクランプされます）。Param Select の閾値はそのまま数で書けます。
  - 入力がソケットなので、上流のフィルタやゲートで絞ったあとの流れを追えます。MIDI Split の下に置けば、その帯で何鍵押さえているかになります。

## Parameter

ソケットは緑

- Constant
- LFO
- Math
- Param Map
- Param Select
- Key Param Select
  - notes 出力から入力したMIDIをそのまま流せます。値を選ぶキーは既定で取り除かれ（[mute picking keys]）、外すと下流にも送られて発音します。
- Envelope Follower
  - オーディオの音量をパラメーター化します。サイドチェイン、ダッカー、レベルメーター、オートゲインの素になります。
  - peak はウィンドウの中の最大値、RMS は二乗平均。attack / release は秒。0 にすると平滑化なしでそのまま追従します。
  - 読みはパラメーター精度ごとなので、attack / release はその1区間より短くできません（既定の 32・48kHz で約0.67ms）。コンプレッサーには十分、クリッパーには足りません。
  - 遅延はありません。測る音を作った段の後で走るので、ある区間で読むウィンドウはその区間自身のものです。

## Plugin

- [+] でパラメーター入力を呼び出せます。
- [GUI] でプラグインのUIが開きます
- [always on] でプラグインが常に有効になります。デフォルトでは出力が繋がっていないプラグインの処理が省略されるので、アナライザなど、出力無しであっても動かしたいプラグインは [always on] で有効にしてください。
